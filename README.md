# Fizika World — онлайн зертхана

**Әртүрлі температурадағы суды араластырған кезде жылу мөлшерлерін салыстыру**

Ыстық және суық суды калориметрде араластыру тәжірибесіне арналған интерактивті симуляция (efizika.ru/33 орнына).

## Жұмыс барысы
1. Ыстық судың (V₁, t₁) және суық судың (V₂, t₂) параметрлерін енгізіңіз.
2. «Пуск» батырмасын басып, плитканы қосыңыз. Су t₁ температурасына жеткенде плитка өздігінен өшеді.
3. Ыстық суды, содан кейін суық суды калориметрге құйыңыз.
4. Калориметрдің термометрі тұрақталған соң қоспаның температурасын (t) жазып алыңыз.
5. «Стоп» батырмасымен келесі тәжірибеге өтіңіз.

Симуляция жылу балансы теңдеуіне негізделген (жылу шығыны жоқ): θ = (m₁t₁ + m₂t₂) / (m₁ + m₂), m = ρV.
Сайт бір `index.html` файлынан тұрады, сервер қажет емес.
